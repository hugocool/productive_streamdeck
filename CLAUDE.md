## Agent skills

Superpowers sets the process; see the orientation list in `AGENTS.md`. The three
settings below are supplemental configuration for the tracker skills (wayfinder,
triage, domain-modeling), telling them where this repo keeps its issues, labels,
and glossary. They describe locations, not workflow.

### Issue tracker

GitHub Issues on `hugocool/productive_streamdeck` via `gh`; writes need the `hugocool` token. See `docs/agents/issue-tracker.md`.

### Triage labels

The five defaults (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
